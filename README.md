# UNDERDOGS Build Lab

Fan-made browser tool for **UNDERDOGS VR** players.

## Prototype features
- Mobile-first weapon search
- Weapon type filters
- Weapon cards with quick role/effect tags
- Two-arm quick build planner
- Links back to community wiki searches for verification

## Data policy
Community wiki information is the starting point. Do not invent exact stats when a reliable source is unavailable; mark uncertain information and verify it before publishing as fact.
